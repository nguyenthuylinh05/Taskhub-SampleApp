# TaskHub - Task Management API

TaskHub is a task management backend API built with FastAPI.

## Tech Stack

- Python 3.12
- FastAPI
- Pydantic v2
- Uvicorn
- Pytest
- Ruff
- MyPy

## Project Architecture

The project follows Layered Architecture:

- API Layer
- Schema Layer
- Service Layer
- Repository Layer
- Core Layer
